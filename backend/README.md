# Platinum Gym - Backend API 🏋️‍♂️

API REST desarrollada con **Node.js**, **Express**, **Prisma ORM** y **MySQL** para gestionar las sucursales, los planes de membresía y el registro de usuarios del gimnasio.

---

## 🚀 Tecnologías y Herramientas
* **Node.js** & **Express** (Servidor y rutas)
* **Prisma ORM** (Gestión y consultas a base de datos)
* **MySQL** (Base de datos relacional)
* **CORS** & **Dotenv** (Seguridad y variables de entorno)
